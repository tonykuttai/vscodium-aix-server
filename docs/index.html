What works

A full remote editing session on AIX

Everything the Linux server does, built for AIX from the same sources.

Bundled Node runtime

The official nodejs.org build for aix-ppc64, the exact version VS Code targets. Only the AIX Toolbox GCC runtime is needed.

Integrated terminals

node-pty compiled on AIX with a small patch, so terminals, tasks and the remote CLI open real ptys on the host.

Fast search

ripgrep built from source for AIX, with PCRE2, at the exact tag VS Code pins. Find-in-files and quick open work as on Linux.

Safe file watching

Polling watchers keep the server away from AHAFS, the AIX kernel file-event system that can wedge a whole machine. Edits show up within a second or two.

Extensions and Git

The extension host runs on AIX, so language servers, Git and the built-in extensions run next to your code.

Verifiable builds

Every package carries a manifest naming the VS Code commit, the fork tag and every native module version, plus a SHA256 on the release page.

How it is built

An AIX host does what GitHub Actions does for VSCodium

VSCodium cannot build AIX in its CI, so a runner on an AIX 7.3 box watches for releases and builds them with VSCodium's own scripts.

Two repositories, one job

The fork holds what could go upstream. The runner holds the rest.

Inside the package

Upstream server, plus a thin AIX layer

VS Code's source is not patched. The AIX work sits in the build target, the native modules and two small files that travel with the server.

Versions

One VSCodium version, three names that must agree

Install

Connect from VSCodium, or unpack it yourself

With the extension

  1. Install the AIX fork of open-remote-ssh in VSCodium.

  2. Add the AIX host to your SSH config and connect.

  3. The extension downloads the server matching your VSCodium version, unpacks it under your home and starts it. If that version has no AIX build yet, it uses the latest one.

By hand, on the AIX host

# V = VSCodium version, C = commit (both on the release page)
$ wget https://github.com/tonykuttai/vscodium-aix-server/releases/download/V/vscodium-reh-aix-ppc64-V.tar.gz
$ mkdir -p ~/.vscodium-server/bin/C
$ tar -xzf vscodium-reh-aix-ppc64-V.tar.gz -C ~/.vscodium-server/bin/C --strip-components 1
$ ~/.vscodium-server/bin/C/bin/codium-server --version

Needs on the host:

AIX 7.3, 64-bit kernel Toolbox libstdc++ and libgcc (GCC 12+) Toolbox krb5-libs GNU tar no root, no Node
